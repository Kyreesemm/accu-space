# Accu Space

Accu Space помогает разобраться, какие файлы и папки занимают место на диске. Проект создан как приложение для анализа хранилища и очистки временных файлов. В репозитории есть графическая версия и консольный режим.

## Возможности

- просмотр доступных дисков и их занятого и свободного места;
- анализ выбранной папки или точки монтирования;
- отображение хода сканирования, категорий файлов и их размеров;
- карта крупных файлов и дерево содержимого папок;
- поиск временных файлов, кэша и других элементов для очистки;
- сохранение отчёта в текстовом и бинарном форматах;
- запуск анализа из терминала.

Размер файла определяется по метаданным файловой системы. Категория назначается по расширению; файлы, для которых категория не определена, попадают в «Другое». Часть системных каталогов исключена из сканирования по умолчанию. Список исключений можно задать через `AnalyzeOptions::ignore_dirs`.

## Запуск

Для сборки понадобится установленный Rust с Cargo. Из корня проекта выполните:

```bash
cargo run
```

Запуск без аргументов открывает графическое приложение. На странице «Диски» можно выбрать том для анализа или перейти к выбору отдельной папки. После сканирования доступны сводка, карта файлов и дерево каталогов.

Чтобы вывести справку по консольному режиму:

```bash
cargo run -- --help
```

Пример анализа папки с сохранением отчёта в указанное место:

```bash
cargo run -- --root ./папка --report-dir ./Disk_Report
```

Число потоков для чтения метаданных можно указать параметром `--workers`:

```bash
cargo run -- --root ./папка --report-dir ./Disk_Report --workers 4
```

Если параметр `--workers` не задан, программа выбирает число потоков автоматически. В консольном режиме корнем анализа по умолчанию является текущая папка.

## Отчёты

Графическое приложение сохраняет текстовый отчёт рядом с анализируемой папкой в каталоге вида `Disk_<имя_папки>_Report`. В нём находятся сводка `summary.json`, а также подкаталоги категорий с файлами `top_files.txt` и `all_files.json`.

Бинарные отчёты `.dar` приложение сохраняет в каталоге `DiskReports` рядом с исполняемым файлом. Такой отчёт можно открыть в приложении через кнопку «Открыть отчёт». В консольном режиме путь для текстового отчёта задаётся параметром `--report-dir`; бинарный отчёт там автоматически не создаётся.

## Сборка

Собрать приложение можно командой:

```bash
cargo build --release
```

В проекте также есть библиотека анализа. Её можно подключить из Rust-кода через крейт `disk_analyzer` и использовать типы `Analyzer`, `AnalyzeOptions` и `AnalysisReport`.
