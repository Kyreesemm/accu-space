# Disk Analyzer

Кроссплатформенный анализатор дискового пространства на Rust с GUI на Slint, библиотекой анализа и CLI.

## Запуск

```text
cargo run
```

Без аргументов запускается графический интерфейс. В нём можно выбрать папку, следить за прогрессом и просматривать категории по размеру. Рядом с текущей директорией создаётся `Disk_<имя_корня>_Report`.

CLI остаётся доступен, если передать параметры:

```text
cargo run -- --root /путь/к/папке --report-dir ./Disk_Report
```

Число рабочих потоков CLI можно ограничить через `--workers N`.

## Что переносит текущая версия

- нативный GUI на Slint с выбором папки, прогрессом, сводкой и открытием отчёта;
- рекурсивное сканирование папки или точки монтирования;
- получение общего, занятого и свободного места средствами текущей ОС;
- классификацию по расширениям и fallback «Игры» для путей, содержащих `game`;
- параллельное чтение размеров файлов с подсчётом пропущенных файлов;
- прогресс, пригодный для передачи в будущий интерфейс;
- `summary.json`, `top_files.txt` и `all_files.json` по категориям.

По умолчанию на Windows пропускаются системные каталоги из старого анализатора, а на Unix-подобных системах — виртуальные каталоги `proc`, `sys`, `dev` и `run`. Это можно переопределить через `AnalyzeOptions::ignore_dirs`.
